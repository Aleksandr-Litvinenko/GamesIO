# GamesIO

Сервис мини-игр, который целиком работает в браузере: ни сборки, ни зависимостей,
ни бэкенда. Витрина показывает каждую игру в «режиме аттракта» — настоящая игра
крутится в карточке под управлением автопилота.

**Сайт:** https://aleksandr-litvinenko.github.io/GamesIO/

| Игра | Что это | Управление |
|---|---|---|
| 🧱 Арканоид / Breakout | 5 уровней, бонусы, мультимяч, неразрушимые блоки | ← → или мышь, пробел — запуск мяча |
| 🐍 Змейка / Snake | сетка 20×20, ускорение по мере роста, золотое яблоко на таймере | ← ↑ → ↓ / WASD / свайп |
| 🏍️ Мотоциклы / Light Cycles | световые мотоциклы против трёх ботов, раунды, буст | ← ↑ → ↓ / WASD, Shift — буст, тап слева/справа |

Пауза — `P` или `Esc`. Рекорды хранятся в `localStorage` браузера.

## Что внутри

Сайт статический и двуязычный: английская версия лежит в корне, русская — в `/ru/`.
У каждой игры своя страница со своим адресом, заголовком, описанием, разделами
«Управление», «Об игре», «Советы» и FAQ — то есть с текстом, который поисковик
может проиндексировать. Одностраничного приложения с хеш-роутером больше нет:
он мешал индексации.

```
https://…/                    английская витрина
https://…/breakout/           Breakout
https://…/snake/              Snake
https://…/light-cycles/       Light Cycles
https://…/ru/                 русская витрина
https://…/ru/arkanoid/        Арканоид
https://…/ru/zmeyka/          Змейка
https://…/ru/motocikly/       Мотоциклы
```

Для поисковых систем и AI-краулеров генерируются:

* `sitemap.xml` — все восемь страниц с `hreflang`-связками между языками;
* `robots.txt` — с явным разрешением для GPTBot, ClaudeBot и PerplexityBot;
* `llms.txt` — краткая карта сайта в формате, который читают языковые модели;
* `games.json` — машиночитаемый каталог игр;
* JSON-LD на каждой странице: `WebSite`, `ItemList`, `VideoGame`, `BreadcrumbList`,
  `FAQPage`, `HowTo`;
* `og:image` 1200×630 на каждую игру плюс общая обложка.

## Структура репозитория

```
src/content.js       весь текст обоих языков и метаданные игр — единственный источник правды
src/templates.js     шаблоны страниц и JSON-LD
src/styles.css
src/js/engine.js     движок: цикл, ввод, звук, частицы, HUD, оверлеи, рекорды, превью
src/js/games/*.js    три игры, каждая — самостоятельный модуль
src/js/app.js        витрина (поиск, фильтр, превью) и запуск одной игры
src/js/ads.js        рекламные слоты — здесь включается монетизация
tools/og.js          рисует обложки 1200×630 для соцсетей
build.js             генератор сайта
docs/                результат сборки, его отдаёт GitHub Pages
```

Механика игр отделена от текста: игра знает только свои размеры и правила, а
названия, подписи и строки внутри канваса приходят из `window.GAMESIO`, который
генератор подставляет на каждую страницу. Поэтому один и тот же код работает на
обоих языках.

### Как добавить четвёртую игру

1. Положить файл в `src/js/games/`, зарегистрировав игру через
   `Arcade.register({ id, width, height, create, autopilot })`.
2. Добавить блок с текстами (оба языка) в массив `GAMES` в `src/content.js`.
3. Добавить путь к файлу в `SCRIPTS` в `build.js` и в список тегов `<script>`
   в `src/templates.js`.
4. `node build.js` — витрина, sitemap, llms.txt и каталог обновятся сами.

## Сборка и запуск

```bash
node build.js
python3 -m http.server 4321
```

Открыть http://localhost:4321/docs/

Сборка также кладёт в `dist/` однофайловую версию витрины (весь CSS и JS внутри
одного HTML) — её удобно закинуть на любой хостинг или открыть с диска.

## Публикация

**GitHub Pages.** Settings → Pages → Deploy from a branch → `main` / `/docs`.
Никакой сборки на CI не нужно, `docs/` лежит в репозитории готовым.

```bash
git push
```

**Hugging Face Space.** Статический Space, зеркало основного сайта:

```bash
hf auth login
hf repo create GamesIO --repo-type space --space_sdk static
git clone https://huggingface.co/spaces/USER/GamesIO hf-space
cp -r docs/* hf-space/
cp deploy/huggingface-README.md hf-space/README.md
cd hf-space && git add -A && git commit -m "GamesIO" && git push
```

Страницы зеркала ссылаются `canonical` на GitHub Pages, поэтому дублей в выдаче
не будет.

## Монетизация

Слоты под рекламу уже размечены: горизонтальный над контентом, прямоугольник
рядом с игрой и баннер в подвале. Пока идентификатор площадки не задан, слоты
скрыты — пустых блоков на странице нет.

Чтобы включить рекламу, впишите свои значения в начало `src/js/ads.js`:

```js
const PUBLISHER_ID = 'ca-pub-XXXXXXXXXXXXXXXX';
const SLOTS = { top: '1234567890', side: '0987654321', bottom: '1122334455' };
```

и пересоберите сайт. Размеры блоков зарезервированы заранее, поэтому реклама не
сдвигает вёрстку при загрузке.

### Что нужно знать до подключения

* **AdSense почти наверняка не одобрит `*.github.io`.** Нужен собственный домен:
  купить, добавить `CNAME` в `docs/`, прописать DNS и поменять `SITE.url`
  в `src/content.js`.
* **`ads.txt` читается только с корня домена.** На `username.github.io/GamesIO/`
  он работать не будет — файл заготовлен на будущее.
* **`robots.txt` — та же история:** краулеры смотрят `username.github.io/robots.txt`,
  а не путь внутри проекта. Пока домена нет, отправьте `sitemap.xml` напрямую
  в Google Search Console и Яндекс.Вебмастер.

## Обновление обложек для соцсетей

`tools/og.js` рисует их на канвасе. Открыть любую страницу сайта, подключить
скрипт и вызвать `renderOg({title, subtitle, badge, accent, emoji})` — вернётся
data URL, который сохраняется в `docs/og/`. Заливки намеренно плоские: градиенты
раздували PNG до 700 КБ.
