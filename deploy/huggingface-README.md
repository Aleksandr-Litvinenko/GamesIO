# GamesIO

Три мини-игры в одной вкладке: **Арканоид**, **Змейка** и **Мотоциклы**
(световые мотоциклы против ботов). Никакой установки и бэкенда — вся страница
работает офлайн, рекорды хранятся в браузере.

Управление: стрелки или WASD, `Shift` — буст в мотоциклах, `P` / `Esc` — пауза.
На телефоне — свайпы и тапы.

Исходники (многофайловая версия): https://github.com/
