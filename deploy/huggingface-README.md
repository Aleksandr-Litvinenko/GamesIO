# GamesIO

Three classic mini-games in one tab: **Breakout**, **Snake** and **Light Cycles**
(Tron-style bikes against three bots). No install, no sign-up, no backend — the
whole page runs offline after the first load and keeps high scores in your browser.

Controls: arrows or WASD, `Shift` to boost in Light Cycles, `P` / `Esc` to pause.
On mobile: swipes and taps. Russian version is available from the header.

- Main site: https://aleksandr-litvinenko.github.io/GamesIO/
- Source code: https://github.com/Aleksandr-Litvinenko/GamesIO

This Space mirrors the main site; every page points its `canonical` link there,
so search engines index a single copy.
